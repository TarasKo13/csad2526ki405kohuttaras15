Коротке резюме з Copilot history — по одному реченню на кожен запит і на кожну відповідь

1) Запит: "Згенеруй просту програму C++ Hello World".
Відповідь: Створив `main.cpp` і `README.md`, а також підготував план і помічні інструкції для збірки та запуску.

2) Запит: "Згенеруй базовий CMakeLists.txt для C++ проекту".
Відповідь: Додав мінімальний `CMakeLists.txt`, який будує `src/main.cpp` як виконуваний файл і оновив todo-статус.

3) Запит: "Напиши unit тест GoogleTest, що перевіряє add(2,3)==5".
Відповідь: Додав три тести (базовий, для від'ємних чисел і для нуля) та `main` для запуску тестів у `unit_tests.cpp`.

4) Запит: "Перезапусти збірку тут з генератором Visual Studio".
Відповідь: Спроба запустити CMake з генератором Visual Studio завершилася помилкою — Visual Studio не виявлено; порадив встановити Visual Studio або використовувати інший генератор.

5) Запит: "Онови CMakeLists, щоб додати FetchContent для GoogleTest".
Відповідь: Оновив `CMakeLists.txt`, додав FetchContent для GoogleTest, створив ціль `unit_tests` і зареєстрував її в CTest.

6) Запит: "Використати MinGW для збірки".
Відповідь: Переключився на MinGW, перевірив `g++`, зібрав проект з `MinGW Makefiles` і успішно запустив тести.

7) Запит: "Напиши batch скрипт для CI на Windows (ci.bat)".
Відповідь: Створив `ci.bat`, який видаляє/створює `build`, виконує `cmake`, `cmake --build` і `ctest`, з перевіркою помилок після кожного кроку.

8) Запит: "Напиши shell скрипт для CI (ci.sh)".
Відповідь: Створив `ci.sh` з `set -euo pipefail`, який очищає збірку, конфігурує, збирає і запускає тести, аварійно виходячи при помилці.

9) Запит: "Створити GitHub Actions workflow для кросплатформної збірки".
Відповідь: Оновив `.github/workflows/ci.yml` з матрицею для `ubuntu-latest`, `windows-latest`, `macos-latest`, що виконує відповідний CI-скрипт і містить заглушку для деплою.

10) Запит: "Перевірте секцію 'Artifacts': якщо там '-', додайте крок upload-artifact після успішної збірки".
Відповідь: Додав кроки `actions/upload-artifact@v4` до workflow, щоб зберегти папку `build` як артефакт для кожного раннера.

Якщо потрібно, можу перевести ці речення англійською, додати більше пар або змінити рівень деталізації.
